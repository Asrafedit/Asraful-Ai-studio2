# Asraful AI Studio Backend

এই folder-টি Render Web Service হিসেবে deploy করার জন্য।

Files:
- server.js
- package.json
- .env.example
- .gitignore
- public/index.html

Render:
Build Command: npm install
Start Command: npm start

Environment Variables:
OPENAI_API_KEY = তোমার নিজের OpenAI API key
OPENAI_MODEL = gpt-5.6-luna

গুরুত্বপূর্ণ: আসল API key GitHub-এ লিখবে না।
